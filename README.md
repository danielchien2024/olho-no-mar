# 🌊 Olho no Mar

Projeto desenvolvido para a disciplina **EC47C – Programação Web Front-End (2026/2)** da Universidade Tecnológica Federal do Paraná (UTFPR).

## Sobre o projeto

O **Olho no Mar** é uma plataforma web colaborativa voltada ao registro e à consulta de ocorrências de poluição marinha, incentivando a participação da comunidade na preservação de praias, oceanos e regiões costeiras.

O projeto está alinhado ao **Objetivo de Desenvolvimento Sustentável 14 (ODS 14) – Vida na Água**, da Organização das Nações Unidas (ONU).

## Funcionalidades propostas

- Cadastro e login de usuários.
- Registro de ocorrências com localização, categoria, descrição e imagem.
- Consulta de ocorrências registradas pela comunidade.
- Divulgação de informações sobre a preservação marinha.

## Tecnologias

- **HTML5 e CSS3:** estrutura e estilização das páginas (Projeto 1).
- **JavaScript:** implementação de funcionalidades interativas (Projeto 2).
