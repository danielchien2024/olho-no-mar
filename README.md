
# 🌊 Olho no Mar

Projeto desenvolvido para a disciplina **EC47C – Programação Web Front-End (2026/2)** da Universidade Tecnológica Federal do Paraná (UTFPR).

## Sobre o projeto

O **Olho no Mar** é uma plataforma web colaborativa voltada ao registro e à consulta de ocorrências de poluição marinha em praias, oceanos e regiões costeiras, alinhada ao **ODS 14 – Vida na Água**.

## Funcionalidades propostas

- Cadastro e login de usuários.
- Registro de ocorrências de poluição marinha.
- Consulta de ocorrências da comunidade.
- Informações sobre preservação marinha.

## Tecnologias

- HTML5
- CSS3

## Estrutura do projeto

| Arquivo ou pasta | Finalidade |
|---|---|
| `index.html` | Login |
| `cadastro.html` | Cadastro |
| `principal.html` | Ocorrências e formulário de registro |
| `sobre.html` | Informações sobre o projeto e a ODS 14 |
| `css/style.css` | Estilos das páginas |
| `assets/images/` | Imagens do site |
| `docs/planejamento.md` | Requisitos do projeto |
